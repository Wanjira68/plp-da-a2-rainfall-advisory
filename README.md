
# Rainfall Advisory Analysis

**Student:** Christine Wanjira

## Project Summary

This project analyses monthly rainfall data from five Kenyan counties: Nairobi, Nakuru, Kisumu, Mombasa and Machakos. It uses Python and NumPy to clean rainfall data, calculate annual totals, identify wettest months, count dry months and recommend planting windows.

## How to Run the Notebook

1. Download or clone this GitHub repository.
2. Install the required library using `pip install -r requirements.txt`.
3. Open `rainfall_analysis.ipynb` in Google Colab or Jupyter Notebook.
4. Run all cells from beginning to end.

## Planting Advisory

- **Nairobi, Nakuru, Kisumu and Mombasa:** April–May is the recommended two-month planting window based on combined rainfall.
- **Machakos:** November–December is the recommended planting window; farmers should plan carefully because the county has six dry months.
- These recommendations are estimates; farmers should also check local weather forecasts and soil conditions, especially because two missing Machakos rainfall values were replaced with the average of valid readings.
